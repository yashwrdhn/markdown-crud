Good distinction. I actually prefer keeping them separate. Here's the revised context:

> **Context:** Alexandria has been restructured into a multi-module Maven workspace with `markdown` (core knowledge engine) and `mcp` (framework-independent Java runtime). The MCP module is functional end-to-end, consisting of JSON-RPC protocol messages, Jackson-based serialization, a `Tool` abstraction, `ToolRegistry`, `Dispatcher`, and an HTTP transport built on the JDK `HttpServer`, successfully invoking registered tools through JSON requests without relying on any SDKs. The infrastructure foundation is now largely complete, so the focus shifts from building frameworks to discovering what Alexandria should fundamentally become. Rather than rushing into AI features, the next phase is to explore high-value problems where AI can provide genuine utility beyond chat, search, or note summarisation, with the goal of identifying the core intelligence layer that will define Alexandria's identity. **ThinkFlow remains a completely separate project**—a future decision/reasoning engine that may integrate with Alexandria if needed, but whose design and evolution are intentionally independent of the knowledge system.
