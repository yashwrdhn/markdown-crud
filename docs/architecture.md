At this stage, Alexandria is transitioning from a single Spring Boot markdown backend into a modular multi-project architecture. The existing markdown module remains unchanged for now and continues to contain both the core markdown functionality and its REST API to avoid unnecessary refactoring. Our immediate focus is to design and implement a lightweight, generic MCP runtime from scratch as a separate Maven module under the parent alex project. Rather than adopting an existing SDK or exactly replicating Anthropic's Model Context Protocol, we'll build our own protocol to understand its architecture end-to-end—covering message formats, tool discovery, registration, invocation, transport, serialization, and extensibility. Once the MCP runtime reaches a stable v1, we'll revisit the architecture and split the markdown module into a reusable core library and a separate Spring Boot server, allowing Alexandria to expose its capabilities through multiple interfaces such as REST, MCP, CLI, or future applications without duplicating business logic.
